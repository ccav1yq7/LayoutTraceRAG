本轮以真实 Workbuddy DeepSeek、已安装 BERT、真实 BGE-M3/重排、主从 Agent、Writer/Verifier、API 和浏览器为目标。订单、说明书和工单使用隔离的自编模拟数据；不冒充实际商家服务或真实客户测试集。人工交接按用户要求排除。

冻结清单：`artifacts/shopguide/customer-acceptance-v1/campaign.json`，SHA-256 `c31366451076de518477ff42580d3853b124c61bd3c6470e89c2a7de534653ae`。12 个场景共 24 条计划用户消息，每 run 最多 12 次调用，新增总上限 288。当前旧累计 870 已耗尽；本轮拟将累计上限提高到 1158，**真实阶段需用户明确批准预算后执行**。费用单价未确认，请求上限不等于金额上限。

场景覆盖商品消歧、指南/原图/追问、故障排查、规则咨询、工单查询与指南混合、申请确认提交查询、暂停撤回、商品切换、上传冲突、缺图和证据不足、并发取消恢复及移动端浏览器。每项保留实际角色、工具、引用、状态与业务账本；判定失败时原行保留，不能重跑成功后替换。涉及缺图/中断的故障注入只作用于该轮独立测试数据。

已准备 `prepare.py` 和受批准文件保护的 `serve.py`。prepare 使用真实本地 BGE 构建测试索引并健康检查，不调用远端 LLM；服务启动前核对批准的 campaign hash、源文件 hash 和累计账本。整个服务进程共享受锁保护的持久请求计数，失败请求也计数。无传输自动重试，Agent 的修复调用仍受每 run 和累计上限约束。
