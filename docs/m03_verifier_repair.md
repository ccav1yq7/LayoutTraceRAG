## 修复内容

模型不再重复抄写长核验 ID。后端为每个待核验项分配固定短键，响应必须覆盖所有键，
再确定性映射回原 claim/step/asset。缺键、多键、错误类型、重复 JSON 键均拒绝；
没有删掉旧重复项来制造成功，也没有把 complete=false 自动改成 true。

整体完成状态新增结构化原因：未完成检查、回答缺项、证据不确定。各项 supported=true
仍不足以强迫整体通过。明确判据后，完整性不足可以被定位，而不是与格式重复混为一类。
详见 [ADR 0010](adr/0010-verifier-keyed-slots.md)。
