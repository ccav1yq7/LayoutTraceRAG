# ADR 0011：无图核验的接口 schema 兼容性

2026-09-10。完整 v5 复测暴露文本核验系统性失败。定向真实请求返回 HTTP 400：
`An object with no properties is not allowed.` 问题来自 images 没有核验项时生成的空对象 schema。
之前带图真实测试及本地空对象单元测试不足以验证这一供应商限制。

## 验收与修复

- schema 递归检查不允许空 properties 对象；测试先在旧实现失败。
- 若有图片核验项，保留原 images 固定键对象；若没有，wire schema 和模型输出都省略
  images 字段，解码后 canonical SemanticVerdict.images 仍为 []。
- 不添加虚构图片项或占位判断，不接受无图响应额外返回图片项；有图场景仍要求全部键。
  duplicate JSON key、缺键、多键、矛盾原因、complete=false、不支持判断等限制保留。
- 提示 fixed-rag-v6，协议 keyed-slots-v2；不调整检索、证据/图片数量或输出 token 预算。
- 生产失败诊断保留匹配 `MODEL_HTTP_[0-9]{3}` 的受控状态码，其他原始异常内容不透传。
  本地回归验证具体 400 可见，附带私人文本的异常仍被遮蔽。

## 证据与运行处置

v5 批次在 117 次请求后停止，留下 59 条完整预测和 1 次尚无完整预测对应的预留。
原始预测及已生成评分保留，但不能把接口兼容性故障污染的批次当作完成的效果复测。
另用 1 次请求确认 HTTP 400，修复后用 2 次请求完成同一实际 B1 问题的 Writer/Verifier，
均成功，累计 120 次请求。

本轮原总上限 750，剩余 630。相同 50 题×3 协议×B1/B2 完整重跑的最坏上限仍为 750，
需要将总上限提高至 870 才能保证整个计划不因上限中断。新 v6 清单先冻结，预算增加
未获批准前不启动；不把故障尝试、定位或修复验证从计数中扣除，不静默重置额度。
