# Synthetic fixtures

The pytest catalog generates five explicitly synthetic products (TEST-100–104),
two principals, separate order items, immutable versions and a self-authored blank
80×40 PNG in temporary storage. It includes same-brand near models and a real
Pillow crop. There are no official benchmark samples, real product instructions,
third-party images or model-generated answers here. Fixtures are for engineering
contracts and isolation only, never model evaluation.
